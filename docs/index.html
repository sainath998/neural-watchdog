Neural Watchdog

A treasury vault on Ethereum Sepolia, guarded by a neural network that runs inside a reactive contract on Reactive Omni. Every withdrawal is scored on-chain, and when the network is more than 90% sure it's watching a drain, it freezes the vault through a callback. There's no oracle and no model server: the AI is part of the running system.

Withdrawal on Sepolia → event → NeuralWatchdog.react() builds 5 features and runs a 5-8-1 network in integer math → p(attack) > 0.9 → callback → vault frozen
